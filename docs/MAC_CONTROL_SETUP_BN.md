# Mac Control — Boss-এর জন্য সেটআপ গাইড

আপনার এজেন্ট এখন আপনার Mac-এ কাজ করতে পারে: terminal কমান্ড চালানো, Claude/Codex সেশন খুলে কাজ করানো, স্ক্রিনশট নেওয়া। এই ফাইলে শুধু আপনার যা করতে হবে সেটুকু আছে।

---

## এক নজরে নিরাপত্তা

| কমান্ডের ধরন | কী হয় |
|---|---|
| **শুধু দেখার** (git status, npm test, ls, cat) | সঙ্গে সঙ্গে চলে, আউটপুট চ্যাটে আসে |
| **কিছু বদলায়** (install, commit, push, ফাইল লেখা) | আপনার ফোনে **approval card** — হুবহু কমান্ডটা দেখে ✅ দিলে তবেই চলে |
| **বিপজ্জনক** (sudo, হোম ফোল্ডার rm -rf, ডিস্ক টুল, .ssh/.env পড়া, curl\|sh, shutdown) | **চলবেই না** — approve করেও না |

আরও:
- আপনার Mac-এ **কোনো দরজা খোলা থাকে না** — Mac নিজে থেকে সার্ভারকে জিজ্ঞেস করে, বাইরে থেকে কেউ ঢুকতে পারে না।
- Mac-এ থাকা নিয়মের কপি নিয়েই এজেন্ট চলে, তাই **সার্ভার hack হলেও** বিপজ্জনক কমান্ড চলবে না।
- সব কমান্ডের স্থায়ী হিসাব থাকে — কী চলেছে, কে অনুমতি দিয়েছে।
- এজেন্ট আপনার পাসওয়ার্ড, key বা `.env` কখনো পড়ে না।

## ধাপ ১ — সুইচ চালু করুন (একবার)

ওয়েবসাইটে **`/agent/mac`** পেজে গিয়ে Mac control সুইচটা **অন** করুন। এটা ডিফল্ট **বন্ধ** — আপনি না খুললে কিছুই চলবে না।

## ধাপ ২ — Mac যুক্ত করুন (একবার)

চ্যাটে লিখুন: **"Mac agent pair code dao"** — এজেন্ট একটা কোড দেবে (১০ মিনিট চলবে)।

Mac-এ Terminal খুলে একবার চালান:

```bash
cd ~/alma-erp/mac-agent && bash install.sh YOUR-CODE
```

এটুকুই। এরপর Mac চালু থাকলে এজেন্ট নিজে থেকেই যুক্ত থাকবে (কম্পিউটার রিস্টার্ট করলেও)।

## ধাপ ৩ — Claude সেশনের জন্য একবার login (শুধু M2-র জন্য)

**এটা লাগবেই** — আপনি Claude **অ্যাপে** logged in, কিন্তু terminal-এর `claude` আলাদা, ওখানে কখনো login করা হয়নি (আমি যাচাই করেছি)। একবার করুন:

```bash
claude
```

খুললে `/login` লিখে লগইন করুন, তারপর বেরিয়ে আসুন। একবার করলেই যথেষ্ট।

Codex সেশনও চাইলে:

```bash
npm install -g @openai/codex
```

## রোজকার ব্যবহার

চ্যাটে স্বাভাবিক বাংলায় বললেই হবে:

- *"Mac-এ git status দেখো"* → সঙ্গে সঙ্গে আউটপুট
- *"test চালাও"* → সঙ্গে সঙ্গে
- *"npm install করে দাও"* → ফোনে card আসবে, ✅ দিলে চলবে
- *"Claude-এ একটা সেশন খুলে এই bug টা ঠিক করতে বলো"* → সেশন খুলবে, অগ্রগতি জানাবে, কিছু জিজ্ঞেস করলে আপনাকে বলবে
- *"এখন কী কী চলছে?"* → চলমান সেশনের তালিকা
- *"স্ক্রিনে কী আছে দেখো"* → স্ক্রিনশট
- *"লম্বা কাজ আছে, Mac ঘুমাতে দিও না"* → keep awake

## থামানোর উপায় (তিনটা)

1. চ্যাটে **"সব থামাও"** — জমে থাকা সব কমান্ড বাতিল
2. `/agent/mac` পেজে সুইচ **অফ**
3. Mac-এ নিজে হাতে:
   ```bash
   touch ~/.alma-mac-agent/PAUSED
   ```
   (আবার চালু করতে ফাইলটা মুছে দিন)

পুরো সরিয়ে ফেলতে:
```bash
launchctl unload ~/Library/LaunchAgents/com.alma.macagent.plist
rm -rf ~/.alma-mac-agent ~/Library/LaunchAgents/com.alma.macagent.plist
```

## কিছু কাজ না করলে

| যা দেখছেন | কারণ ও সমাধান |
|---|---|
| "আপনার Mac অফলাইন" | Mac ঘুমিয়ে আছে বা বন্ধ। জাগান। |

লগ দেখতে: `tail -f ~/.alma-mac-agent/agent.log`

## যেটা এখনো সম্ভব নয় — এবং কেন

**Mac আনলক করা যায় না।** macOS ইচ্ছাকৃতভাবে lock screen-এ programmatically পাসওয়ার্ড দিতে দেয় না। যেসব উপায় আছে সেগুলোর জন্য আপনার পাসওয়ার্ড প্লেইন টেক্সটে রাখতে হয় — সেটা আপনার সবচেয়ে বড় নিরাপত্তা দুর্বলতা হয়ে দাঁড়াবে, তাই বানানো হয়নি।

**দরকারও নেই:** স্ক্রিন lock থাকা অবস্থাতেও এজেন্ট terminal-এর সব কাজ ও Claude সেশন চালাতে পারে — শুধু আপনি Mac-এ log in করা থাকলে আর Mac ঘুমিয়ে না গেলেই হবে। তাই "keep awake" আছে, আর Apple Watch দিয়ে auto-unlock চালু রাখলে আপনি কাছে গেলেই খুলে যাবে।
