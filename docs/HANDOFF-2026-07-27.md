## 1. What shipped today

### The honesty round (PR #622, #623)
The agent used to claim things it had not done. Six fixes, each found live:

- **duplicate guard** — the idempotency key was claimed when the guard *allowed*
  a call, not when the effect happened, so a failed `draft_seo_fixes` locked the
  same batch out for ten minutes. Released on every failure path.
- **"card বানাচ্ছি"** was invisible to the verifier (the whole বানা- family was).
- **a staged pending action counts as a real card** — otherwise the widened regex
  would punish truthful claims.
- **the opening line is a claim too.** Speak-first streams before any tool runs
  and survives every rewrite, so a promise made there was unfalsifiable. Now it
  must be corrected. *Live-proven:* the agent wrote *"(কার্ড তৈরি করতে পারিনি,
  সেটা সংশোধন করলাম।)"*
- **card state is read, not asserted** — every turn carries the server's count.
- **the card may only report a decision he actually made.** `owner_decided` is
  written solely by the approve/reject routes. `resolvedAt` was the wrong signal
  (the worker's job-result callback stamps it too) — my first fix was wrong and
  the live check caught it. *Live-proven:* the audit card now reads
  "অনুমোদন লাগেনি — নিজে থেকেই হয়ে গেছে".
- **leaked tool-call markup** — both the XML dialect and the JSON one
  (`{"type":"tool_use",…}`), the second seen in his own chat.

### Finishing the job instead of stalling (PR #622)
- **a work turn gets a work-sized budget** — a deep turn was allowed 60 rounds
  while the head's tool budget stripped its tools after 8.
- **a job keeps its size** — the work class is remembered for the conversation
  (45-min expiry, widening only).
- **a corrected retry is not hammering** — the failure guard reads the error
  *class* now, so "the arguments were wrong, doing it properly" gets pushed.
- **after he answers, it works instead of asking again.**
- **the loop.** Raising the push limit produced one: three server notes arrived
  as plain `user` messages, the head read them as Boss repeating himself and
  answered each by saving memory — **45 steps, $0.90**. Fixed on three legs:
  every server note carries an INTERNAL CONTROL marker (including the periodic
  constitution reminder), a push must be **earned** by a non-bookkeeping tool
  success, and it **escalates** instead of repeating. *Live-proven on DeepSeek V4
  Flash: 21 steps, $0.03, no loop, and an honest negative finding.*
