# Mac-এর ফোল্ডার গোছানো

**এই skill-এর একটাই আকৃতি: তালিকা দেখাও → Boss অনুমোদন দিন → তারপর সরাও।**
নিজে থেকে কিছু সরানো নয়, আর **মুছে ফেলা কখনো নয় — যা বাদ, তা Trash-এ**।

## যেভাবে কমান্ড চলে (এখানে না জানলে ধাক্কা খাবে)

- cwd **সবসময় ডিফল্টেই রাখো** (`~/alma-erp`)। `cwd` হিসেবে `~/Downloads` দিলে
  Mac সরাসরি `cwd_not_allowed` ফেরত দেবে — অনুমোদিত ফোল্ডারের তালিকা কোডে বাঁধা।
- বাইরের ফোল্ডার ছোঁয়া হয় **আর্গুমেন্ট দিয়ে**: `ls -la ~/Downloads`,
  `mv ~/Downloads/a.pdf ~/Downloads/PDF/`।
- প্রজেক্ট ফোল্ডারের বাইরের যে-কোনো পথ ছুঁলেই সেটা **approval card** হয়ে যায় —
  এমনকি শুধু `ls`-ও। তাই কার্ডের সংখ্যা কমাও: **একটা card = একটা পুরো ধাপ**,
  ফাইলপ্রতি একটা নয়। approve-এর পর ফল `check_mac_command` দিয়ে নাও।

## ধাপ

```
- [ ] ১. কী আছে দেখো (এক card)
- [ ] ২. দল বানাও, Boss-কে দেখাও — এখানে থামো
- [ ] ৩. ফোল্ডার বানাও + সরাও (এক card)
- [ ] ৪. মিলিয়ে দেখো, কী দাঁড়াল বলো
```

১. **দেখা** — `ls -la ~/Downloads` (বা তিনি যে ফোল্ডার বললেন)। বড় ফাইল খুঁজতে
   `du -sh ~/Downloads/*` । গোনো: কয়টা ফাইল, কোন ধরনের, মোট কত জায়গা।
   **যা দেখোনি তা নিয়ে পরিকল্পনা কোরো না।**

২. **পরিকল্পনা** — সহজ, অনুমানযোগ্য দল: `PDF/`, `Images/`, `Installers/`,
   `Invoices/`, `Archive-2026-06/` — তারিখ বা ধরন, দুটোর একটা; মিশিয়ে ফেলবে না।
   Boss-কে বাংলায় দেখাও: **কয়টা ফাইল কোথায় যাচ্ছে, আর কতটা জায়গার ফাইল নড়ছে**।
   **"এত জায়গা খালি হবে" বলবে না** — একই ডিস্কে ফোল্ডারে সরালে এক বাইটও খালি হয়
   না, আর Trash-এ গেলেও Boss নিজে Trash খালি না করা পর্যন্ত জায়গা ফেরে না। বলতে
   হলে এভাবে: "Trash-এ যাচ্ছে ২.১ GB — আপনি Trash খালি করলে ওইটুকু ফেরত আসবে"।
   **এখানে থামো** — তিনি হ্যাঁ না বলা পর্যন্ত পরের ধাপ নয়।

৩. **সরানো** — `mkdir -p ~/Downloads/PDF` তারপর `mv`। এক card-এ যতটা সম্ভব
   একসাথে। নিয়ম:
   - **একই নাম গন্তব্যে থাকলে থামো** — চাপা পড়ে যাওয়া মানে ফাইল হারানো।
     `mv -n` (no-clobber) ব্যবহার করো, আর কোনটা বাদ পড়ল সেটা বলো।
   - **নাম বদলাতে হলে নিয়ম আগে বলো** (যেমন `2026-06-12-invoice-alma.pdf`) এবং
     সেই নিয়মেই সব — একেকটার একেক রকম নয়।
   - **কোড ফোল্ডারে হাত নয়** — `~/alma-erp` জাতীয় কিছুর ভেতর এই skill ঢোকে না।

৪. **মিলিয়ে দেখা** — সরানোর পর আবার `ls` দিয়ে গুনে দেখাও: আগে কয়টা, এখন কয়টা,
   কোন ফোল্ডারে কয়টা। **"গুছিয়ে দিয়েছি" বলার আগে এই গোনাটা থাকতে হবে।**
   জায়গার হিসাব দিলে **"সরানো হয়েছে" আর "খালি হয়েছে" আলাদা করে বলো** — দ্বিতীয়টা
   Trash খালি করার আগে কখনো সত্যি নয়।

## যা বাদ দিতে হবে

`rm` **কখনো নয়** — এই skill কোনো অবস্থাতেই delete করে না। Boss "মুছে দাও"
বললেও কাজটা Trash পর্যন্ত:

```
osascript -e 'tell application "Finder" to delete POSIX file "/Users/<user>/Downloads/<file>"'
```

Trash-এ গেলে ভুল হলেও ফেরানো যায়; `rm`-এ যায় না। Boss স্থায়ীভাবে মুছতে চাইলে
সৎভাবে বলো: **Trash খালি করাটা তাঁর নিজের কাজ**, আমি করব না।

## এই skill-এর নিজের নিষেধ

- **`rm` নয়, `rm -rf` নয়, `find -delete` নয়, Trash খালি করা নয়।**
- **তালিকা না দেখিয়ে একটা ফাইলও সরানো নয়।**
- **অচেনা ফাইল আন্দাজে সরানো নয়** — নাম দেখে বোঝা না গেলে আলাদা রেখে জিজ্ঞেস করো।
- **কী/গোপন ফাইল (`.env`, `.pem`, key) ছোঁয়া নয়** — কোডেই বন্ধ, চেষ্টাও কোরো না।
- **কোড checkout-এর ভেতর ঢোকা নয়** — সেখানে "অগোছালো ফাইল" আসলে git-এর কাজ।
- **overwrite নয়** — সন্দেহ হলে থামা, চাপা দেওয়া নয়।

## Boss-কে কী বলবে

দুই ধাপে। আগে: **কয়টা ফাইল, কোন দল, কোথায় যাবে, কত জায়গা ছাড়বে** — তারপর অপেক্ষা।
পরে: **কয়টা সরল, কয়টা বাদ পড়ল আর কেন, এখন ফোল্ডারটা দেখতে কেমন**।
